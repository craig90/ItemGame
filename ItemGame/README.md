### React SpringBoot App

# Run instructions

Springboot Backend

cd to project root
./gradlew build
./gradlew bootRun

React Frontend
cd frontend
npm run dev

### Desktop App

# Run instructions
There are two options:

1. Run the project through the Launcher in VSCode.
Literally open the Launcher.java program and select run.

2. The project can also be run using gradlew.
cd to project root
./gradlew build
./gradlew desktop:run
